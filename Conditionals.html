Conditionals: if → then

Условное предложение — это две половинки. Первая говорит «если…», вторая — «то…». Весь секрет в том, какое время стоит в каждой половинке.

если (условие)If it rains, то (результат)we will stay at home.
Тип 0 · Zero Conditional

Факты, которые верны всегда

If + Present Simple,Present Simple

Законы природы, правила, привычки. «Если» здесь можно заменить на «когда».

If you heat ice, it melts.

Если нагреть лёд, он тает. (всегда)

Тип 1 · First Conditional

Реальное будущее

If + Present Simple,will + глагол

Вполне возможная ситуация в будущем. Это самый частый тип в ОГЭ.

If it rains tomorrow, we will stay at home.

Если завтра пойдёт дождь, мы останемся дома.

If I break my promise, mum will get upset.

Если я нарушу обещание, мама расстроится.

Главная ловушка

По-русски мы говорим «если пойдёт дождь» — в будущем. А в английском после if будущее время не ставим, только Present Simple.

If it will rain → If it rains

Тип 2 · Second Conditional

Мечты и «если бы»

If + Past Simple,would + глагол

Нереальная или маловероятная ситуация сейчас. По-русски — «если бы…, то бы…». Глагол после if выглядит как прошедшее время, но речь о настоящем.

If I had more free time, I would learn Spanish.

Если бы у меня было больше времени, я бы учила испанский.

If I were you, I would watch this series.

На твоём месте я бы посмотрела этот сериал. (с if часто пишут were для всех лиц)

Подсказка для ОГЭ

Видишь во второй половине would → после if ставь прошедшую форму: had, went, knew, were.

То же правило после I wish: I wish you had another hobby! — «Жаль, что у тебя нет другого хобби».

Тип 3 · Third Conditional

Сожаление о прошлом

If + had + 3-я форма,would have + 3-я форма

Прошлое, которое уже не изменить. В ОГЭ встречается редко, достаточно узнавать его.

If I had known, I would have helped you.

Если бы я знала (тогда), я бы помогла тебе.
